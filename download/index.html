Download RizzStudio

Free for macOS 14+ on Apple Silicon. Install it in under a minute.

Download RizzStudio 1.1.0

RizzStudio-macOS.zip · macOS 14 Sonoma or later · Apple Silicon (M1 and newer)

Install in three steps

  1. Download RizzStudio-macOS.zip and double-click to unzip it.
  2. Drag RizzStudio.app into your Applications folder.
  3. The first time only, right-click the app and choose Open, then confirm. macOS asks once because the app isn't notarized yet.

If macOS still refuses to open it, run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/RizzStudio.app

Optional: turn on AI planning

RizzStudio uses the AI coding CLI you already have, so you don't need an API key:

  • Claude Code 2.1.280 or newer (Settings has an update button), or
  • Codex CLI

Without either, the built-in rules engine still programs a complete show.

What you'll want for a real rig

  • Ableton Live to play the exported show
  • TouchDesigner to output Art-Net or sACN (the receiver component is bundled)
  • An Art-Net / sACN node or USB DMX interface, and your fixtures

No rig yet? The 3D stage preview and MP4 export work with nothing plugged in.

What's new in 1.1.0

  • 3D moving heads: perspective stage, pan/tilt-accurate yoke and head, beam cones with floor spots, gobos and lens flare
  • Fixture profiles: generic channels remapped to each fixture's real DMX personality, from the Open Fixture Library, AI, a datasheet or by hand
  • TouchDesigner receiver .tox bundled inside the app
